One line: a museum placard for an ordinary office object, written as if it
were an ancient artifact dug from a lost civilisation.

> Binder Clip, c. 1300 BCE. Iron jaw that held the empire's receipts together; released only at the coronation. On loan from Accounts.

The joke: the humblest desk object recast as an instrument of imperial
bureaucracy — it held the empire's receipts, and was released only at the
coronation. "On loan from Accounts" is the provenance: the museum label
itself is still filed with the department that owns it. Deadpan throughout,
no wink, every clause in the curator's voice.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: every run writes the identical 132-byte line. The program
self-checks the 1–180 character gate before writing.
